# הכנה לבילד הפורס-אפדייט — הודעת "מה חדש" + חתימה-מחדש על התנאים

> מסמך הרצה. **שום דבר כאן לא פעיל עד שתריץ אותו במפורש.** הפורס-אפדייט + החתימה-מחדש יוצאים **רק בבילד שתחליט עליו** — לא ב-OTA רגיל.
> מנגנון החתימה-מחדש זהה בדיוק לזה שהיה ביוני 2026 (`TermsUpdateModal` + `TermsReconsentGate`) — רק התוכן והגרסה מתעדכנים.

## איך זה עובד (2 מנגנונים נפרדים)
1. **פורס-אפדייט** — חוסם גרסאות ישנות ומפנה לחנות. נשלט ע"י **קונפיג מרוחק** (`app-config.json` ב-Vercel Blob), לא ע"י קוד. `ForceUpdateScreen` מציג `title`/`message`/`ctaLabel` מהקונפיג. שינוי הקונפיג לא דורש OTA.
2. **חתימה-מחדש על התנאים** — מודל חוסם (`TermsUpdateModal`) שמופיע כשגרסת התנאים שהמשתמש אישר ישנה מ-`CURRENT_TERMS_VERSION`. מציג את בּוּלֶטֵי `TERMS_UPDATE_SUMMARY_HE` (עיקרי השינויים המשפטיים) + checkbox + כפתור **"אישור והמשך"**, וקישור לתנאים המלאים. מי שלא מסכים → "מחיקת חשבון". **משתמשים חדשים לא רואים אותו** (הם מקבעים את הגרסה הנוכחית ב-onboarding).

## מוכן כבר (על הענף, בלי טריגר)
- ✅ **בּוּלֶטֵי החתימה-מחדש** — `src/lib/legal/termsVersion.ts`, `TERMS_UPDATE_SUMMARY_HE`/`EN` עודכנו עם 4 השינויים החברתיים (עמוד חברים, פרופיל-בהסכמה, תוכן-קהילה+מודרציה, התערבויות-וירטואליות ללא כסף אמיתי). דוֹרְמַנְטִים עד שהגרסה תעלה.
- ✅ **כותרת המודל** — `TermsUpdateModal.tsx`: "מה השתנה ביולי 2026:".
- ✅ **מסמך התנאים** — `docs/finplay-terms-and-privacy.md` עודכן (סעיף 13 קהילה/תוכן-גולשים, התאמת סעיף 3 להתערבויות-וירטואליות, פרטיות: איסוף תוכן חברתי + פרופיל ציבורי). *יש לפרסם את הגרסה המעודכנת ל-finplay.me (ריפו נפרד).*

## הטריגר היחיד לחתימה-מחדש (מוחזק — להריץ רק עם בילד הפורס-אפדייט)
בקובץ `src/lib/legal/termsVersion.ts`, לשנות שורה אחת:
```ts
export const CURRENT_TERMS_VERSION = '2026-06-04b';   // ← לפני
export const CURRENT_TERMS_VERSION = '2026-07-03';    // ← אחרי (מפעיל חתימה-מחדש לכל המשתמשים הקיימים)
```
**חשוב:** את השינוי הזה לשלב **רק בבילד/OTA של הפורס-אפדייט**, לא לפני — אחרת משתמשים קיימים יחתמו מחדש מוקדם מדי.

## הודעת הפורס-אפדייט (קונפיג מרוחק — `app-config.json`)
לפרסום דרך `scripts/publish-app-config.ts` ל-Vercel Blob. זה הטקסט שיופיע במסך החוסם:

```json
{
  "enabled": true,
  "minSupportedVersion": "1.4.3",
  "iosStoreUrl": "itms-apps://apps.apple.com/app/id6761650222",
  "androidStoreUrl": "market://details?id=com.finplay.app",
  "title": "עדכון חדש מחכה לכם",
  "message": "שדרגנו את FinPlay: יומן משקיעים חדש עם אירועי המקרו של החודש; עמוד חברים — חדרי שיח, חכמת המונים, ליגת פנטזי ולוחות מובילים; שיפורי יציבות וחוויה בשיעורים; ותנאי שימוש מעודכנים. כדי להמשיך, עדכנו לגרסה החדשה מהחנות.",
  "ctaLabel": "לעדכון בחנות",
  "publishedAt": "2026-07-04T00:00:00Z"
}
```
- `minSupportedVersion` = גרסת הבילד החדש (עדכן ל-version שתפרסם בפועל; `1.4.3` = גרסת היעד). כל גרסה נמוכה ממנו נחסמת.
- `iosStoreUrl` — החלף במזהה האפליקציה האמיתי ב-App Store.
- `enabled: true` = הפעלה. כרגע בפרודקשן זה `false` (כבוי) — הפורס-אפדייט לא פעיל עד שתפרסם את זה.

## צ'קליסט שחרור (בסדר הזה)
1. **בילד נייטיב חדש** (1.4.3) שכולל את יומן-המשקיעים + השינויים החברתיים + תיקון קריסת Scudo של אנדרואיד 16 (RN 0.83.6) + את שינוי `CURRENT_TERMS_VERSION` → `'2026-07-03'`. העלאה ל-App Store + Google Play, אישור והפצה.
2. **פרסם את מסמך התנאים המעודכן** ל-finplay.me (privacy-policy + terms-of-service).
3. **המתן** שהבילד יאושר ויהיה זמין בחנויות בשתי הפלטפורמות.
4. **פרסם את `app-config.json`** עם `enabled:true` + `minSupportedVersion` = הגרסה החדשה (`scripts/publish-app-config.ts`). מרגע זה משתמשים בגרסאות ישנות רואים את מסך הפורס-אפדייט.
5. משתמש שמעדכן ופותח מחדש → **מודל החתימה-מחדש** (`TermsUpdateModal`) עולה, מציג את 4 הבּוּלֶטים החברתיים + כפתור "אישור והמשך".
6. **מייל לכל המשתמשים הרשומים** עם סיכום השינויים + קישור לתנאים המלאים (לפי מדיניות הפרטיות §8). תבנית: `src/features/email/`.
7. **אימות:** משתמש קיים → פורס-אפדייט → חנות → פתיחה → חתימה-מחדש → אישור → המשך. משתמש חדש → כניסה חלקה בלי מודל.

## rollback
- כיבוי הפורס-אפדייט: פרסם `app-config.json` עם `enabled:false` (או `minSupportedVersion:"0.0.0"`). מיידי, בלי OTA.
- החתימה-מחדש לא ניתנת ל-rollback בקלות (מי שכבר אישר — אישר); לכן לוודא שהתוכן נכון **לפני** שמעלים את הגרסה.
