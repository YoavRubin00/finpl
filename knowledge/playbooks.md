# 📕 playbooks — SOPs לצוות FinPlay

> נהלי עבודה משותפים. מצביעים ל-source-of-truth הקיים, לא מכפילים.
> מתוחזק על ידי **מאיה**.

## P1 — להצמיד KPI להמלצה
כל המלצה של כל סוכן חייבת: **(1) מדד אחד מדיד** (אירוע PostHog מ-[[glossary]]), **(2) בעל-תפקיד אחד** שמבצע (יואב/תומר/אורי/נווה או סוכן AI), **(3) קישור ליעד** ₪400K. ניסוח: "X: לבצע Y — KPI: `event` לפי breakdown Z — מועד: תאריך". בלי "הצוות יעשה" כללי.

## P2 — לאמת נתון פיננסי (וארן)
1. סרוק `src/features/chapter-*/...Data.ts`, `daily-challenges/*data*.ts`, `glossary/glossaryData.ts`.
2. לכל נתון (מס/ריבית/מע"מ/פנסיה) — חפש מקור עדכני (taxes.gov.il, בנק ישראל).
3. דווח: קובץ + שורה + כתוב/נכון + מקור + שנת מס. **אל תמציא — "לא הצלחתי לאמת" אם אין מקור.**
4. תקן רק אחרי אישור, ב-data files בלבד (לא קוד).

## P3 — לכתוב קופי פונה-משתמש
1. **קרא `docs/BRAND.md`** ([[brand-voice]]) — חובה לפני מילה ראשונה.
2. בחר מין דקדוקי לפי מי מדבר (קפטן שארק יחיד נטול-מין / מערכת רבים).
3. ≤15 מילים ב-UI, 0–2 אמוג'י, עברית ישראלית.
4. אם נשמע פרסומת/מורה — כתוב מחדש. עבור קופי רגיש (paywall/bridge/hearts) → הרץ `/אודרי`.

## P4 — להוסיף תוכן באפליקציה (יוצרון)
1. קרא דוגמה קיימת מאותו סוג (`chapter1Data.ts` / `dilemma-data.ts` וכו') — התאם ל-interface.
2. IDs ייחודיים (בדוק שלא מתנגשים). קוויז = 4 תשובות + הסבר. דילמה = 2 אפשרויות הגיוניות + תובנה.
3. **אל תשנה תוכן קיים — רק הוסף.** ודא `npx tsc --noEmit` נקי.
4. נתון פיננסי בתוך התוכן → אמת מול P2 / `/וארן`.

## P5 — לפני release (קפטן)
tsc נקי (0) → `expo export` נקי → app.json מלא → assets קיימים → אין secrets חשופים → version bump. רק אז build+submit.

## P6 — מתי לקרוא לאיזה סוכן
ראה מטריצת החפיפות ב-[[agent-registry]]. כלל אצבע: **קוד** → ארכיטקט/הסורק/קפטן · **מוצר/UX** → יפיופי/דואו/מוני/רטנשן · **תוכן** → יוצרון/וארן/אודרי · **שיווק** → בר/טרנדון/מושן · **אסטרטגיה** → yoatzon · **תחזוקת סוכנים** → maya.

## P7 — Onboarding סוכן חדש (מאיה)
1. הגדר דמות חדה + KPI יחיד + רשימת `knowledge:` לטעון.
2. כתוב ל-`.claude/agents/<שם>.md` (subagent) או `.claude/commands/<שם>.md` (slash), עם frontmatter תקין + שורת "טען INDEX קודם".
3. רשום ב-[[agent-registry]] עם `version: A`.
4. תעד ב-OS `audits/agent-evals/`. אם רלוונטי — הצע ליואב A/B ראשון.
